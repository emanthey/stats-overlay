# Stats Overlay

A small always-on-top overlay that shows CPU, RAM and GPU usage, with a native version for Windows and one for Linux.

```sh
git clone https://github.com/emanthey/stats-overlay.git
```

| Platform | Folder | How to run |
| --- | --- | --- |
| Windows | [`windows/`](windows/README.md) | Run `build.bat`, then start `StatsOverlay.exe` |
| Linux | [`linux/`](linux/README.md) | Install the GTK packages, then run `python3 statsoverlay.py` |
